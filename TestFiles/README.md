# TestFiles

Hand-testing fixtures for the checks in [manual-checklist.md](../manual-checklist.md).
Nothing here is loaded by the automated tests — the MopedEditor package tests use
inline fixtures — these files exist to be opened in the running app.

| Folder | What it exercises |
|---|---|
| `Languages/` | One sample per language with its own tokenizer: open each and check the picker reads the right name and highlighting appears. The alias-backed names (`scss`, `less`, `kotlin`, `groovy`, `objectivec`, `erb`, `twig`, `handlebars`, `asciidoc`) borrow another language's tokenizer and have no sample yet. |
| `EdgeCases/` | Tokenizer edge cases: multiline CDATA, fenced code in Markdown, an unterminated C comment. |
| `Encodings/` | UTF-8 and UTF-16 files with byte-order marks — both must open as text. |
| `Sizes/` | The size tiers: small/medium/large open normally, `Huge.txt` (2 MB) crosses the 256 KB large-file threshold. The 8 MB and over-16 MB fixtures are generated by `scripts/make-size-fixtures.sh` (gitignored). |
| `PlainFallback/` | Languages with no tokenizer — must open as plain text, no crash. |

For the binary-refusal check there is no committed fixture (a Mach-O binary does not
belong in git): generate one with `cp /bin/ls probe.dat` and check Moped refuses it.
